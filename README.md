# EncryptionProject--ForFun--
A python project I did after I haven't really been touching python in June this year. 
It is only used and intended for Latin alphabets (without tone) 

How it works:
1. User will generate key from option 1
2. User will enter the text that they want to encrypt
3. User enter key that was generated before
4. User will receive their text

I don't really use AI for this project except for these two premises:

[1]. Generating the Character_Set and Password_Set
[2]. the text.replace function
